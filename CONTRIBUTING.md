# Contributing

## Rules
- Keep docs aligned with actual implementation state and clearly label planned scope.
- Use the canonical names: **User Resolution Center** and **Stage 3A — User Operations and Resolution**.
- Preserve MVP timetable publishing behavior while extending docs for Stage 3A.
- Do not introduce unrelated LMS/helpdesk/ERP scope.
- Document every new environment variable and Google scope when implementation adds them.
- Add tests with behavioral changes and update `TASKS.md`, `ROADMAP.md`, and QA/test docs together.
